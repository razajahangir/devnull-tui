# Changelog

## v0.1.0

First public release of this unofficial /dev/null terminal client.

- Feeds, threads, profiles, compose, stars, saves, follow
- Production default (`https://dev-null.sh`) with `--url` / config for other instances
- Per-instance device keys, signed `/api/v1` requests
- Read-only settings file with flag → env → file → default precedence
- Lane colors from the website
- Refresh: `R` reloads this screen and marks other tabs stale; optional auto-load and refresh-on-switch
